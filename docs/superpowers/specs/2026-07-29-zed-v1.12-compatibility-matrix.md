global-state race at `crates/gpui/src/profiler/actions.rs`. Every affected test

`test_extension_store_with_test_extension` after all three remote-sync tests
had passed. The matrix uses those focused synchronization regressions; the
unrelated broad fixture is not claimed as passing.

## macOS bundle and smoke

The bundle script produced and ad-hoc signed:

`target/aarch64-apple-darwin/debug/bundle/osx/Flint.app`

As documented in the repository instructions, the script then exited non-zero
because its debug path attempted to gzip
`target/aarch64-apple-darwin/release/remote_server`. The fresh bundle was
copied to `/tmp/Flint-Local.app` after preserving the prior copy as
`/tmp/Flint-Local.app.pre-wave8`.

Validation:

- executable: Mach-O 64-bit arm64;
- bundle identifier: `dev.flint.Flint`;
- signature: valid ad-hoc signature satisfying its designated requirement;
- running executable:
  `/private/tmp/Flint-Local.app/Contents/MacOS/flint`;
- extensions loaded: 4;
- workspace initialized and opened;
- Git repository opened at `/Users/shxi/projects/flint/.git`; and
- application log recorded `Rendered first frame`.

The debug app reported expected local-development warnings: missing release
signing credentials and a debug hang-detection trace. Neither prevented
startup or first-frame rendering.
