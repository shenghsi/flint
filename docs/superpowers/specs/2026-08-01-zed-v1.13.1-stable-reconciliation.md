# Zed v1.13.1 Stable Release Reconciliation

**Date:** 2026-08-01

**Previous upstream baseline:** Zed `v1.12.1`
(`2a37601c02a32b22e7700835c04b89ff75ffcd5d`)

**Reviewed upstream baseline:** Zed `v1.13.1`
(`00bd72e7838f4b875a913cd112b47a0ebe1ca62b`)

**Scope:** Stable release notes and the fixed `v1.12.1..v1.13.1` tag diff;
tags ending in `-pre` are excluded.

## Method

The review exported the 100 unique pull-request links in Zed's v1.13.1
release body and resolved them against the immutable v1.13.1 tag. It also
inspected the complete 169-commit, 285-file tag diff so release-body edits or
missing release-note attribution could not hide changes in Flint-relevant
paths. For every selected safety fix, the review inspected the upstream pull
request, stable-tag commit, affected paths, later changes on Zed main, and the
corresponding current Flint behavior.

Release-note presence does not authorize a behavior or product change. Changes
outside the selected safety set remain deferred until a focused reproduction,
test-first Flint adaptation, and review establish that they should alter
Flint. Native Agent Panel, hosted model-provider, MCP settings, account, and
sign-in-only changes remain excluded by Flint's product boundary.
