# Zed v1.6-v1.12 Stable Release Reconciliation

**Date:** 2026-07-29

**Flint fork point:** `6e9465a4288c332208643892e23b9d35d7be5c79`

**Final upstream baseline:** Zed `v1.12.1`
(`2a37601c02a32b22e7700835c04b89ff75ffcd5d`)

**Scope:** Stable release notes only; tags ending in `-pre` are excluded.

## Method

The audit exported pull-request links from the GitHub release bodies for every
non-preview tag from Zed v1.6 through v1.12, deduplicated them by PR number,
and resolved each PR's final merge commit and affected paths. It then:

1. tested whether each merge commit is an ancestor of Flint's fork point;
2. compared absent commits with canonical pre-fork commits by stable patch ID;
3. checked whether each affected path survives in current Flint;
4. reused terminal evidence in the upstream ledger;
5. inspected stable-release safety, corruption, crash, hang, and data-loss
   candidates separately; and
6. inspected later upstream corrections before selecting an implementation.

The stable source set contains 568 unique PRs. Preview-only entries are not
used as discovery inputs, even if their commits later occur in a stable tag's
Git ancestry.
