# Command Palette

The Command Palette is the main way to access actions in Flint. Its keybinding is one of the first shortcuts to learn: {#kb command_palette::Toggle}.

![The opened Command Palette](https://flint.dev/img/features/command-palette.jpg)

To try it, open the Command Palette and type `new file`. The command list should narrow to {#action workspace::NewFile}. Press Return to create a new buffer.

Any time you see instructions that include commands of the form `flint: ...` or `editor: ...` and so on that means you need to execute them in the Command Palette.
