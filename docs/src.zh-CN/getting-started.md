# 开始使用 Flint

安装并打开 Flint 后，请打开一个现有文件夹或创建一个新文件。Flint 将这个文件夹称为项目。

使用命令面板可以查找操作。默认快捷键是 `cmd-shift-p`（macOS）或 `ctrl-shift-p`（Linux 和 Windows）。命令面板也接受英文操作名称。

使用设置编辑器可以选择界面语言。打开 **Flint > 设置 > 打开设置**，然后在 **常规设置** 中选择 **简体中文**。语言更改会立即应用，不需要重新启动 Flint。

其他页面仍在翻译。请使用[英文文档](/docs/getting-started.html)查看完整说明。
