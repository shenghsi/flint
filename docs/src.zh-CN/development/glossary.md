# Flint 术语表

本术语表定义 Flint 界面和中文文档中的常用术语。操作标识符、设置 JSON
路径、代码和命令保持英文。

- **Agent Thread（智能体线程）**：一个智能体会话及其历史记录。
- **worktree（工作树）**：Git 仓库的一个工作目录。它可以是本地或远程目录。
- **project（项目）**：Flint 中打开的一个或多个工作树。
- **buffer（缓冲区）**：文件内容在内存中的表示形式。
- **Command Palette（命令面板）**：用于搜索和运行操作的界面。
- **Settings Editor（设置编辑器）**：用于查看和更改设置的界面。
- **Restricted Mode（受限模式）**：限制项目代码和任务执行能力的安全模式。
- **extension（扩展）**：为 Flint 添加语言、主题或工具支持的可安装组件。
- **language server（语言服务器）**：提供补全、诊断和导航等语言功能的外部进程。
- **debugger（调试器）**：用于控制调试会话、断点和变量的界面。
- **terminal（终端）**：用于运行命令和查看其输出的集成终端。
